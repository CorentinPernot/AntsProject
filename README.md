# 🐜 Projet Ants : L'union fait la force – optimisation par colonie de fourmis

## Présentation

Simulation d'une colonie de fourmis, réalisée dans le cadre du cours de programmation de 1A.

**Auteurs** : Sacha Apelbaum & Corentin Pernot

---

## 🎯 Objectifs

- Déplacement d'agents (fourmis) selon des règles locales
- Dépôt, diffusion et évaporation de phéromones
- Visualisation de comportements collectifs

---

## ⚙️ Fonctionnalités

- Grille 2D
- Agents autonomes (classe `Agent`)
- Phéromones gérées par la classe `Game`
- Animation avec `matplotlib`
